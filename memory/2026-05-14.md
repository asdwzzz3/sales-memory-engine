## 2026-05-14 17:15-17:50 - 销售易CRM浏览器自动化成功（v1→v8迭代）

### 背景
- 大智手上没有电脑，无法手动操作CRM，要求用浏览器自动化提取拜访记录
- 之前尝试过API方式（v1-v3）均失败：schedule-list.action返回空，needScheduleGuide=1标志未完成引导

### 迭代路径
| 版本 | 关键问题 | 解决方式 |
|------|---------|---------|
| v1-v3 | API返回空 | 放弃纯API，转向浏览器自动化 |
| v4 | 定位器语法错误 | 修复逗号分隔的字符串 |
| v5 | 弹窗遮挡、表格0行 | 强制JS移除弹窗 + 多种选择器尝试 |
| v6 | 表格结构解析失败 | 发现Ant Design虚拟滚动，传统table选择器无效 |
| v7 | 弹窗导致页面空白 | 组合策略：点击"不再显示"→ESC→JS强制移除→等待 |
| v8 | 成功提取71条，翻页4页 | JS遍历包含日期+客户的元素，向上查找行容器 |

### 关键技术教训

**1. 弹窗处理（Ant Design + 产品更新）**
- 不能只用JS remove()，需要先点击"不再显示"和"关闭"让系统记住偏好
- 组合策略：
  1. 点击"不再显示"和"关闭"
  2. 点击X按钮
  3. 按ESC
  4. JS强制移除.ant-modal-wrap, .ant-modal-mask, .el-dialog
  5. 清理body.modal-open类

**2. 表格提取（Ant Design虚拟滚动）**
- `page.locator("table tbody tr")` 返回0行——页面实际使用div布局
- 正确方法：JS遍历所有包含`2026-`和`客户`的元素，向上查找最近的`tr`或`.ant-table-row`或`[class*="row"]`
- 去重：用Set记录已处理的innerText

**3. 分页处理**
- 活动记录共4页，每页20条
- 检查下一页按钮：`document.querySelector('.ant-pagination-next')`，判断disabled类
- 点击后等待5秒加载
