  2. 点击X按钮
  3. 按ESC
  4. JS强制移除.ant-modal-wrap, .ant-modal-mask, .el-dialog

- 正确方法：JS遍历所有包含`2026-`和`客户`的元素，向上查找最近的`tr`或`.ant-table-row`或`[class*="row"]`
- 去重：用Set记录已处理的innerText

**3. 分页处理**
- 活动记录共4页，每页20条
- 检查下一页按钮：`document.querySelector('.ant-pagination-next')`，判断disabled类

### 技术实现

#### 核心问题：mem0 embedding安装
- fastembed默认模型需要从网络下载 → 磁盘满/网络失败
- 解决：直接用预下载的 `~/.cache/fastembed/models/fast-all-MiniLM-L6-v2/model.onnx`

#### 自定义Embedding：OfflineMiniLMEmbedder

- 机制：绕过`fastembed`包，直接用`onnxruntime`加载本地ONNX模型
- 注册方式：import时自动注入`EmbedderFactory.provider_to_class`
- 模型：MiniLM-L6-v2，384维，ONNX本地推理，0网络依赖

#### 向量存储：FAISS（替代Chroma）
- 原因：Chroma在脚本环境中偶有不稳定
- FAISS配置：`embedding_model_dims=384`，本地文件存储
- 路径：`/tmp/mem0_faiss/`

#### LLM后端：DeepSeek via OpenRouter
- 模型：`deepseek/deepseek-v4-flash:free`
- 原因：中国区唯一可用的免费OpenRouter模型
- Kimi Key不兼容OpenAI格式（401），OpenRouter上OpenAI/Kimi模型被403

#### 稳定性策略：infer=False

- AutoGen官方已进入**维护模式**，微软推出新框架 Microsoft Agent Framework 1.0
- **不推荐**：安装旧版autogen（legacy core）
- **推荐**：autogen-agentchat（v0.4架构）+ 自定义轻量客户端

### 技术实现

#### 安装
```bash
pip install autogen-agentchat==0.7.5
pip install openai  # 轻量客户端依赖
```

#### autogen_ext官方客户端问题
- `OpenAIChatCompletionClient` 初始化报错 `AsyncContextManagerError`
- 原因：autogen_ext的client对非OpenAI原生模型支持不好，OpenRouter的deepseek模型metadata不匹配

#### 解决方案：手搓轻量客户端
- 绕过autogen_ext重的模型层
- 保留autogen_agentchat的**编排框架**（GroupChat, RoundRobin等）
- 直接用OpenAI库+OpenRouter，接入AutoGen对话编排

#### 3-Agent Demo架构
```
用户任务 → RoundRobinGroupChat
  ├─ 销售助手（分析拜访优先级）
  ├─ 监控助手（风险补充）
  └─ 决策助手（汇总行动清单）
```

### Demo结果
| Agent | 产出 |
|-------|------|
| 销售助手 | 矿务总院 > 盱眙中医院 > 儿童医院 |
| 监控助手 | 挂网节点监控、竞品风险、招标参数准备 |
| 决策助手 | 周一确认挂网时间、周二跟进张主任、周三儿童医院 |

### 技术结论
- **AutoGen能装进身体，但需要"改装"**
- 不用autogen_ext模型层，用autogen_agentchat编排层+自定义OpenRouter客户端
- 未来"小智+张经理+监控Agent"架构可行
